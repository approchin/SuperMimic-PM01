# 模型卡：SuperMimic PM01 checkpoint 65k

本文记录首版模型的身份和使用边界。模型文件的最终摘要以 [`models/SHA256SUMS.json`](../models/SHA256SUMS.json) 为准，评测细节见[评测说明](evaluation.md)。

## 模型身份

| 项目 | 内容 |
| --- | --- |
| 公开名称 | SuperMimic PM01 checkpoint 65k |
| 任务 | PM01 参考动作条件下的全身跟踪 |
| 训练 seed | 13；本轮只有一个主模型 |
| 快照位置 | 65,000 个采集推进步，非优化器更新次数 |
| 训练最终状态 | 99,918 步，因持续实际跟踪退化停止；未宣称收敛 |
| Actor 参数量 | 8,480,055 |
| 轻量 Actor | `models/actor_0000065000.pt` |
| 可移植导出 | `models/actor_65000_fp32.onnx`，opset 13，含观测及参考归一化 |
| 默认参考目标 | `reference_only_v0`，不启用 `goal_feedback_v1` |
| 权重许可 | [非商业科研模型许可 v0.1](../models/LICENSE.md) |

PT 是轻量 Actor 文件，不能用作完整学习恢复点。公开 PT 已清理嵌入式私有元数据，26 个张量与原训练文件逐字节一致；元数据重存改变了 PT 的文件摘要。ONNX 保持原文件，导出元数据中的源 PT 摘要记录的是原训练文件；公开 PT 应按发布校验清单核对。

## 输入与输出

| 张量 | 形状 | 含义 |
| --- | --- | --- |
| `obs_hist` | `[1, 10, 78]` | 从旧到新的 10 帧本体历史；首帧填满历史 |
| `goal` | `[1, 630]` | 10 个未来参考帧，每帧 63 维 |
| `action23` | `[1, 23]` | 23 个身体关节的归一化动作 |

每帧本体观测由以下字段顺序拼接：

1. 24 维关节角减默认角及校准偏移，单位 rad。
2. 24 维关节角速度，单位 rad/s。
3. 基座坐标系中的 3 维角速度，单位 rad/s。
4. 基座坐标系中的 3 维单位重力方向。
5. 上一拍实际发出的、已裁剪并含头部的 24 维动作。

未来帧偏移为 `[5,10,15,20,25,30,35,40,45,50]`；在 50 Hz 参考上对应 0.1 至 1.0 秒。每个未来帧包含参考相对位置 3 维、旋转前两列 6 维、参考根线速度 3 维、根角速度 3 维、关节角 24 维与 `0.1 × 关节速度` 24 维。越过动作结尾时重复末帧。

这里的位置目标是“未来参考位置减当前参考位置”，以当前参考朝向表示；它不等于机器人到未来参考点的实际位置误差。Actor 本体观测不包含实际根位置或根线速度。`goal_feedback_v1` 曾作为其他历史实验中的自定义反馈修正，未加入此模型的训练和本文列出的原参考评测，不能将其作为 65k 已学到的能力。

Actor 的参考编码器为 `630→2048→1024→512→256→32`，最后一层使用 tanh；解码器将 32 维参考隐变量与 `10×78` 维归一化历史拼接，使用 `812→2048→1024→512→256→23` 网络。隐藏层为 ELU。

推理核心将当前参考头部 yaw 补入第 24 维，将组合动作裁剪到 `[-20,20]`，再按默认角、校准和关节缩放得到目标角。具体关节顺序、缩放及名义 PD 数值见 [`inference/robot_spec.json`](../inference/robot_spec.json)；它们需要与输入的模型空间定义一致。策略频率为 50 Hz。

## 训练来源

本模型来自 PM01 的单 seed 新训练。训练底座使用 HoloMotion/PyTorch SuperMimic 前端与原生 MuJoCo-Warp 物理后端，保留 Actor、世界模型 F 与 Critic。F 学习仿真采集的下一状态；Actor 在 F 中生成的想象轨迹上，结合参考奖励及 Critic 尾值优化。部署只导出 Actor。

训练池记录为 3,982 条片段/变体：3,950 条通用 PM01 重定向动作，另加 16 条跑步、过渡或跳跃参考及其 16 条准入镜像/修正版。通用池的来源记录为 3,700 条 BONES 来源及 250 条 CMU 来源，新增跑跳参考来自 LAFAN1。这个数量包含切窗和数据增强，不能解释为 3,982 次独立录制。

Training data includes [Motion Data by Bones Studio](https://bones.studio/).

Use of the underlying dataset is subject to the [BONES Motion Capture Dataset License Agreement](https://bones.studio/info/seed-license).

本轮加入了每回合固定的 0/5/10/15/20 ms 执行延迟，待执行完整关节目标和时序状态进入采集、经验、F 与想象接口。训练使用 CUDA BF16 MLP 前向；权重张量以 FP32 保存。完整数据、原始训练日志和最终完整恢复点不随首版分发。已公开源码的可运行范围与版本差异见 [`training/`](../training/) 和[发布范围](release_scope.md)。

## 数值精度与结果解释

| 环节 | 已记录的数值方式 | 能支持的结论 |
| --- | --- | --- |
| 训练及三项固定 200 复测 | 原生 CUDA BF16 MLP；复测摘要回读 `torch.bfloat16`，TF32 开关开启 | [评测说明](evaluation.md)中的原生仿真成绩 |
| ONNX 导出 | FP32 前向，包含归一化 | 可移植的 Actor 接口 |
| CPU 推理检查 | ONNX Runtime CPU，合成输入 | 文件、形状与有限数值检查 |
| 跟踪视频 | CPU MuJoCo + ONNX Runtime FP32，八段 BONES 参考按实际误差与动作特点精选 | 单独的协议、逐段观察和精确误差，见[视频页](videos.md) |
| 补充实现配对 | 20 条原始全片，PyTorch CUDA BF16 Actor + 同一 CPU 物理 | 与 CPU ONNX 父片分列，不能单独归因于精度，不是原生 Warp 历史复现 |
| 既有目标设备检查 | TensorRT FP32，少量已记录输入 | 这些输入上的导出对照和纯推理计时 |

FP32 导出不意味着整条闭环轨迹与训练评测的 BF16 前向一致。既有目标设备对照使用四个记录状态：站立与步行各两个时刻。FP32 与源实现 FP32 的数值对照通过；与历史原生 BF16 已发指令相比，23 维身体目标最大差约 `0.0038965 rad`（`0.2233°`），该比较也包含后端差异。它不是全动作闭环等价证明。

固定 200 条动作的完成率约为 97% 至 97.5%，但这是原终止门限下的完整片段完成率。它不保证精确位置跟踪、低关节误差、硬件稳定性或未见任务的表现。完整公式、帧覆盖与失败解释见[评测说明](evaluation.md)。

## 真机状态与适用边界

曾进行受控接管和约 1 秒软接管探针；初轮出现抽动，后续敬礼入场也触发速度保护。**持续 SuperMimic 静站、完整敬礼及完整手柄流程尚未验收通过。** 首版保留这一结果边界，后续再整理现场经验。

现场曾加入首包连续处理、目标限速、实际已发目标回写和踝阻尼调试，模型权重没有改变。这些现场执行设置不能当作原训练配方或既有仿真成绩的设置；本首版也不提供现场启动链路。

该模型适用于算法阅读、离线推理和进一步的仿真研究。完整参考动作、训练资产及其再分发权利需要使用者另行取得；首版合成输入仅用于接口检查。单 seed、开发集反复使用及未完成的硬件验收共同限制了可作出的结论。
