# 首版发布范围

v0.1.0 提供 PM01 适配代码、可校验的 checkpoint 65k 权重、离线推理入口，以及仿真结果和使用范围。

## 包含内容

| 部分 | 首版范围 |
| --- | --- |
| 训练实现 | HoloMotion/SuperMimic 的相关源码与 PM01 适配、评测接口及训练说明 |
| 推理核心 | 本体历史、原参考目标、归一化、Actor 与 24 维目标组合 |
| 数值规格 | 推理所需的关节顺序、默认姿态、缩放与名义控制参数 |
| 模型 | 65k 轻量 Actor、FP32 ONNX、元数据和摘要清单 |
| 检查工具 | 文件摘要核对；使用合成输入的 CPU ONNX 推理检查 |
| 发布材料 | 分层架构图、两组实验结果图及脱敏汇总、八段 BONES 闭环跟踪视频和对应协议 |
| 文档 | 模型卡、既有评测协议和结果、硬件验收边界、上游归属 |

GitHub 代码仓库包含源码、文档、演示和校验清单。PT 与 ONNX 通过项目首页的权重入口分发。[权重入口](../README.md#4-权重与离线使用)

PT 已清理嵌入式私有元数据，26 个张量与原件逐字节一致；文件摘要因元数据重存改变。公开文件的摘要以发布清单为准，不能将公开 PT 的文件摘要写成原训练文件摘要。

## 复现限制

首版能够支持离线推理接口检查，以及阅读和改造训练实现。完整训练与历史闭环评测还依赖未随首版分发的数据和资产。

此外，本地训练源码是已有工作树副本；不能默认它与实际运行机器上每个时刻的文件完全一致。该轮还涉及 MuJoCo-Warp 的 EPA 容量和 CUDA 捕获缓冲生命周期修补。只有源码、已安装依赖、补丁、机器人规格与数据版本都对齐后，才具备讨论完整复现的前提。提供通用训练入口不能替代最终实际配方，轻量 Actor 也不能替代完整恢复点。

已完成合成输入的 CPU 离线接口检查。演示取自单独录制的 CPU MuJoCo + ONNX Runtime FP32 闭环，历史 BF16 结果来自原始报告及脱敏汇总。完整训练和原生历史评测的复现仍需单独核对数据、资产及运行环境。[实验介绍](experiments.md) · [演示协议](videos.md)
