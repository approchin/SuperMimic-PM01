# 65k 选片和探索记录

## 首版展示

首版八段均为 BONES 参考，采用 65k Actor 的 CPU ONNX FP32 全片闭环结果。选片覆盖不同动作类型，同时考虑实际关节与根位置误差。八段都执行至参考末帧，原五项优选条件同时达标为 0/8。这些是开发后效果精选。单 seed 与源录制重合情况未确定限制了对未见动作泛化的判断。[视频页](videos.md) · [逐段精确统计](../media/results/showcase_tracking_65k.csv)

## 前期候选探索

首轮按实际闭环效果探索展示候选，使用同一个 65k 模型。264 条全片结果中，260 条是当轮 CPU 运行，4 条复用既有轨迹。163 条完整执行，1 条满足下述全部首选门。前期探索中的全片、事件窗口和配对结果均保留在候选 CSV。其中 `video_selected`、`in_main_reel` 和 `video_role` 字段记录当时的探索用选片标记。首版正式视频以逐段清单为准。[候选 CSV](../media/results/video_quality_selection_v2.csv) · [首版逐段清单](../media/videos/showcase/manifest.json)

完整 CSV 的 292 行是三轮真实条件记录：264 条原参考条件、8 个独立重置事件窗口、20 个精度与后端配对条件；其中包含 4 条既有轨迹复用。窗口和配对反复使用父参考，因此不是 292 个独立动作，也不是 292 个统计独立样本。各轮的完成数和质量门分别报告。

## 固定首选门

要求完整执行、所有主指标有效，并同时满足：

| 指标 | 门限 |
| --- | ---: |
| 23 个受控关节 MAE | ≤ 6° |
| 23 个受控关节 RMSE | ≤ 9° |
| 全程最大 root XY 差 | ≤ 0.20 m |
| 末帧 root XY 差 | ≤ 0.15 m |
| root XYZ RMSE | ≤ 0.10 m |

判断使用未四舍五入数值。根部全程误差和最大偏移参与门限，避免仅凭末帧接近隐藏中程漂移。提前终止保留首次终止步和之前全部实测帧；失败尾部不补零、不重复末帧，不拿短前缀冒充整段完成。

难度与误差分别报告。关节活动量、转向和参考跳跃结构描述动作；文件名不能证明策略真的跳起。完整候选的误差 Pareto 前沿同时比较 MAE、关节 RMSE、root XYZ RMSE、最大 XY、末帧 XY 五项；它描述误差取舍，并不等于质量门通过。全完整候选前沿有 8 条，CSV 的 `error_pareto_front` 给出成员；在完整且参考跳跃语义与实际飞行重叠的候选中，误差前沿是 Q047、Q053、Q060。

## 指标与闭环运行

前两轮 Actor 使用 ONNX Runtime CPU FP32，物理使用 CPU MuJoCo 3.3.7。控制 50 Hz、物理 200 Hz，零执行延迟，无噪声、推扰或中途重置。每条只从参考首帧的位姿与速度初始化一次，之后读取实测状态闭环控制自由根机器人。历史原生 GPU BF16 结果只用于寻找线索，不进入前两轮排名；最后新增的第三轮配对见文末独立协议。

主误差统计实际执行后的 `t=1..N`，排除共同初态与参考驱动的头部。23 受控关节按原始弧度差、各关节各时刻等权：MAE 为绝对差均值转角度，RMSE 为全部差平方均值开根再转角度。位置使用原始世界坐标，不另做平移、航向或逐帧对齐。root XYZ RMSE 为 `sqrt(mean(dx²+dy²+dz²))`，XY 为 `sqrt(mean(dx²+dy²))`；这是向量欧氏 RMS，不是每轴 RMS，也不是平均欧氏距离。最大和末帧 XY 差为对应时刻的水平欧氏距离。缺失指标留空，不能解释为零。

原终止门保持根高度差 >0.25 m、跟踪身体点高度差 >0.30 m、完整根旋转误差平方 >0.8 rad² 及非有限数检查。水平漂移不直接触发原生终止，因此完成与位置精度分列。各轮全部已记录轨迹均独立重算核对指标、时轴、关节顺序、覆盖和摘要。

新增运行的实际飞行按 200 Hz 物理状态检查地面接触与原物理足底几何：连续至少 60 ms 无机器人与地面接触，双足最低净空峰值至少 2.5 cm，前后有足部地面接触；参考几何段需双足净空 >1 cm 至少 3 个 50 Hz 帧、峰值至少 2.5 cm，且前后有边界帧。接触由真实状态下的碰撞几何距离判定，未测量承重接触力。4 条 v1 复用只有 50 Hz 控制状态，按该采样率重建的接触记录单独标记，不用于严格跳跃确认。正时间重叠只说明事件相符；视频仍须显示实际起跳、腾空与落地。单脚跑步的腾空不能仅凭这个检测称为双脚同时蹬地跳。

## 范围与素材身份

前期探索先扫描 5,799 条参考，其中 331 条具有上述参考几何腾空结构，再在候选池执行。实际尝试数以 CSV 为准。既有 18 条专项参考和 16 条镜像未在前三轮执行。

CSV 对每条使用稳定 alias，区分精确训练 ID 成员、源录制重合、历史开发曝光与本轮开发精选身份。已从原 65k 权重内保存的 3,982 个精确训练 ID 逐项核对，首轮仅 Q083、Q084、Q085、Q087 是精确训练成员；额外本地参考的精确 ID 均不在该清单中。`training_seen` 与 `exact_training_id_member` 指精确条目，源录制或近邻素材重合另用 `source_recording_overlap_with_training` 表示，未核时保留 `unknown`。历史 validation 动作已经用过；固定监控面板也是开发资料。本轮没有盲测，源录制层面的独立性未作全面核查。

本结果仅支持这些固定参考初态下的仿真展示。真机从静站接入、结束退出和长期控制仍是独立验收项目。素材署名与使用范围见[第三方说明](../THIRD_PARTY_NOTICES.md)及[媒体许可](../media/LICENSE.md)。
