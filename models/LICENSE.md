# SuperMimic PM01 非商业科研模型许可

**版本 0.1，2026-11-20。**

## 适用对象与许可范围

本许可适用于 SuperMimic PM01 v0.1.0 的 checkpoint 65k Actor、FP32 ONNX，以及由这些文件转换或修改的模型文件。代码采用独立许可。原始动作数据、机器人资产和第三方程序按各自来源条款管理。

在发布者有权授权的范围内，发布者授予接收者免费、非独占的许可，供**非商业科学研究、教学和评测**使用、复制、转换、修改及再分发这些模型。再分发须附本许可、模型卡、数据来源与第三方声明。对模型所作修改应清晰标明，并继续按本许可提供。商业使用和发布者无权授予的第三方权利均不在本许可范围内。

## 使用条件

1. 保留项目名称、对应版本和上游署名，以及模型卡与 README 中 BONES 要求的两句署名。不得暗示上游作者或数据提供者认可、担保本项目或后续用途。
2. 不得借助模型提取、还原或转发受保护的原始动作数据。公开或再分发的模型及其修改版本须符合底层 BONES 原数据不可从中提取、逆向还原或重新取得的条件。本次整理未对模型作全面的不可逆验证。不得以模型或其结果创建、改进或扩充 BONES 协议定义的竞争数据集，或可在商业上替代其原数据的合成数据集。
3. 不得将模型用于需要故障安全保证的危险场景，包括武器系统、关键基础设施或医疗设备。
4. 来源数据的独立条款继续按其实际适用范围约束相应用途。本许可不会解除已有第三方条件，亦不限制依法无需许可即可进行的行为。

训练来源包含 BONES、CMU 和 LAFAN1，原数据及其重定向、镜像参考均不随模型分发。出处与条款见 [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md)。BONES 对结果权利和用途设有条件；LAFAN1 原数据采用 CC BY-NC-ND 4.0。

将本模型定位为非商业科研，并不自动判定训练模型是否属于第三方作品的改编。本许可不转授权原数据，不授予第三方未授予的改编分发权，也不承诺模型不涉及任何第三方权利。若具体用途需要超出已取得权利的授权，须从相应权利人另行取得。

模型按现状提供，不作适用性、准确性或特定硬件运行保证。已记录成绩属于相应仿真协议。持续真机静站、完整敬礼和完整手柄流程尚未验收。文件完整、CPU 推理及短时接管各有独立的验证范围。
